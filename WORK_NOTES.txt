■ 1. 프로젝트 개요
--------------------------------------------------------------------------------
Python + discord.py 기반 Discord 봇.

봇 이름   : Tactician Bot
실행 방법 : python src/bot.py  (프로젝트 루트에서 실행)
주요 기능 :
  · 슬래시 명령 (/ping, /공지설정, /공지, /멤버목록, /출석조회, /활동통계)
  · 공지 채널 설정 + 모달로 공지 임베드 게시
  · 멤버목록 채널 자동 생성·게시 + CSV 다운로드 버튼
  · 음성/메시지 활동 집계 (KST 일별) → activity.json 저장

■ 4. Discord 설정 (Developer Portal)
--------------------------------------------------------------------------------
[필수 Intent]
  Message Content Intent  — 메시지 수 집계(on_message)에 필요
  Server Members Intent   — 멤버 목록·캐시(guild.chunk / fetch_members)에 필요

  위치: Applications → Bot → Privileged Gateway Intents

[초대 권한 권장]
  OAuth2 → URL Generator
  Scopes : bot, applications.commands
  권한 예시:
    · 메시지 보내기 / 임베드 링크 / 파일 첨부
    · 채널 관리 (멤버목록 채널 자동 생성)
    · 서버 관리 권한은 슬래시 default_permissions와 별개
      (실제 사용 제한은 명령의 Manage Guild 기본 권한으로 걸림)

[Bot Token]
  .env의 DISCORD_TOKEN에 저장. Git에 올리면 안 됩니다.


■ 5. 환경 변수
--------------------------------------------------------------------------------
  DISCORD_TOKEN  — (필수) 봇 토큰
  GUILD_ID       — (선택) 지정 시 해당 서버에 슬래시 명령 즉시 동기화
                   미설정 시 전역 동기화 (반영 최대 약 1시간)
                   GUILD_ID가 있으면 활동 집계도 그 서버만 추적

  설정:
    cp .env.example .env
    cp data/config.example.json data/config.json   # 필요 시
    cp data/activity.example.json data/activity.json


■ 6. 슬래시 명령어
--------------------------------------------------------------------------------
[bot.py]
  /ping        — 생존 확인 (Pong!)
  /공지설정    — 공지 올릴 텍스트 채널 지정 → data/config.json 저장
  /공지        — 모달(제목·내용)로 공지 임베드 게시
  /멤버목록    — Manage Guild 필요
                 "멤버목록" 채널 찾거나 생성 후 목록 게시
                 CSV 다운로드 버튼(1시간)

[activity_tracker.py]
  /출석조회    — Manage Guild 필요
                 멤버(기본: 본인) 출석일수·음성·메시지 요약 + 최근 7일
  /활동통계    — Manage Guild 필요
                 서버 전체 활동 CSV ephemeral 첨부


■ 7. 활동 집계 (activity_tracker)
--------------------------------------------------------------------------------
저장 파일 : data/activity.json (KST Asia/Seoul 기준 일별)

집계 항목:
  voice_joins     — 음성 채널 입장(또는 채널 이동) 횟수
  voice_seconds   — 음성 체류 초 (자정 넘기면 날짜별 분배)
  voice_messages  — 음성/스테이지 채널 채팅 수
  messages        — 일반 텍스트 채널 메시지 수

출석 판정:
  해당 날짜에 위 항목 중 하나라도 > 0 이면 출석일

데이터 형태(요약):
  {
    "<guild_id>": {
      "_guild_name": "...",
      "<user_id>": {
        "_user_name": "...",
        "YYYY-MM-DD": {
          "voice_joins": 0,
          "voice_seconds": 0,
          "voice_messages": 0,
          "messages": 0
        }
      }
    }
  }

봇 재시작 시:
  이미 음성에 있는 멤버는 on_ready에서 세션만 동기화
  (재시작 직전 구간 초는 누락될 수 있음)


■ 8. bot.py / 모듈 구조
--------------------------------------------------------------------------------
bot.py
  load_dotenv() → TOKEN / GUILD_ID
  data/config.json 로드·저장 (공지·멤버목록 채널)
  setup_hook → ActivityTracker Cog 로드
  on_ready
    · 슬래시 sync (guild 또는 global)
    · GUILD_ID 있으면 guild.chunk()로 멤버 캐시
    · 설정된 채널 상태 로그
  슬래시: ping / 공지설정 / 공지 / 멤버목록

activity_tracker.py
  ActivityStore  — JSON 읽기/쓰기·집계
  ActivityTracker Cog
    · on_voice_state_update / on_message
    · /출석조회, /활동통계
  setup_activity_tracker(bot, guild_id)


■ 9. 발생했던 오류 / 주의
--------------------------------------------------------------------------------
  ValueError: DISCORD_TOKEN 미설정
  → .env 없거나 DISCORD_TOKEN 비어 있음
  → cp .env.example .env 후 토큰 입력

  PrivilegedIntentsRequired
  → Message Content / Server Members Intent 미활성화
  → Developer Portal에서 ON 후 재실행

  슬래시 명령이 안 보임
  → GUILD_ID 설정 후 재시작(즉시 sync) 권장
  → 전역 sync는 최대 약 1시간 소요
  → 초대 시 applications.commands 스코프 포함 여부 확인

■ 11. 실행 순서
--------------------------------------------------------------------------------
  1. pip install -r src/requirements.txt
  2. .env에 DISCORD_TOKEN (및 선택 GUILD_ID) 설정

  5. python src/bot.py

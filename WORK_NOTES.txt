■ 1. 프로젝트 개요
--------------------------------------------------------------------------------
Python + discord.py 2.7+ 기반 Discord 봇 + FastAPI REST API.

봇 이름   : Tactician Bot
실행 방법 :
  python src/main.py   봇 + REST API (Railway / 외부 조회)
  python src/bot.py    봇만 실행
주요 기능 :
  · 슬래시 명령 (아래 §6 전체 목록)
  · /명령설정 — 역할별 명령 사용 제한 (Modal)
  · 공지 채널 설정 + Modal로 공지 임베드 게시
  · 멤버목록 채널 자동 생성·게시 + CSV 다운로드 버튼
  · /팀정하기 — 팀 구성·멤버 선택·랜덤 팀 배정 (봇 제외)
  · /채팅삭제 — 채널 메시지 일괄 삭제
  · 음성/메시지 활동 집계 (KST 일별) → activity.json 저장
  · 공식 TFT 패치·소식 수집 후 규칙 기반 요약 → Discord 알림
  · Steam 스토어 할인 게임 수집 → Discord 알림
  · REST API로 기간별 출결·활동 조회 (포인트 계산은 외부 시스템)

■ 4. Discord 설정 (Developer Portal)
--------------------------------------------------------------------------------
[필수 Intent]
  Message Content Intent  — 메시지 수 집계(on_message)에 필요
  Server Members Intent   — 멤버 목록·/팀정하기 멤버 Select에 필요

  위치: Applications → Bot → Privileged Gateway Intents

[초대 권한 권장]
  OAuth2 → URL Generator
  Scopes : bot, applications.commands
  권한 예시:
    · 메시지 보내기 / 임베드 링크 / 파일 첨부
    · 채널 관리 (멤버목록 채널 자동 생성)
    · 메시지 관리 (/채팅삭제)
    · 서버 관리 권한은 슬래시 default_permissions와 별개

[Bot Token]
  .env의 DISCORD_TOKEN에 저장. Git에 올리면 안 됩니다.


■ 5. 환경 변수
--------------------------------------------------------------------------------
  DISCORD_TOKEN  — (필수) 봇 토큰
  GUILD_ID       — (선택) 지정 시 해당 서버에 슬래시 명령 즉시 동기화
                   미설정 시 전역 동기화 (반영 최대 약 1시간)
                   설정 시 활동 집계·REST API·TFT/Steam/팀정하기도 그 서버만
  API_KEY        — (REST API 필수) Authorization: Bearer <API_KEY>
  PORT           — REST API 포트 (기본 8000, Railway는 자동 주입)
  CONFIG_FILE    — (선택) config.json 경로. Volume 예: /data/config.json
  ACTIVITY_FILE  — (선택) 활동 JSON 경로. Volume 예: /data/activity.json
  TFT_DIGEST_FILE — (선택) TFT 알림 상태 JSON. Volume 예: /data/tft_digest.json
  TFT_POLL_MINUTES — (선택) TFT 확인 주기(분). 기본 30
  STEAM_DIGEST_FILE — (선택) Steam 알림 상태 JSON. Volume 예: /data/steam_digest.json
  STEAM_POLL_MINUTES — (선택) Steam 확인 주기(분). 기본 60
  STEAM_MIN_DISCOUNT — (선택) Steam 최소 할인율(%). /스팀알림설정으로도 변경 가능
  STEAM_CC / STEAM_LANG — (선택) Steam 스토어 지역/언어. 기본 kr / korean
  STEAM_SEARCH_COUNT — (선택) Steam 검색 할인 게임 수. 기본 100

  Railway Volume (재배포 후 설정 유지):
    Mount Path: /data
    Variables:
      CONFIG_FILE=/data/config.json
      ACTIVITY_FILE=/data/activity.json
      TFT_DIGEST_FILE=/data/tft_digest.json
      STEAM_DIGEST_FILE=/data/steam_digest.json

  로컬 설정:
    cp .env.example .env
    cp data/config.example.json data/config.json
    cp data/activity.example.json data/activity.json


■ 6. 슬래시 명령어
--------------------------------------------------------------------------------
[bot.py]
  /ping        — 생존 확인 (Pong!)
  /공지설정    — 공지 올릴 텍스트 채널 지정 → config.json 저장
  /공지        — Modal(제목·내용)로 공지 임베드 게시
  /멤버목록    — Manage Guild 필요
                 "멤버목록" 채널 찾거나 생성 후 목록 게시
                 CSV 다운로드 버튼(1시간)
  /채팅삭제    — Manage Messages 필요
                 텍스트 채널 최근 메시지 1~100개 삭제 (14일 이내만 일괄 삭제 가능)
                 봇에 해당 채널 메시지 관리 권한 필요

[command_toggles.py]
  /명령설정    — Manage Guild 필요
                 Modal에서 명령 + 역할 선택 (둘 다 여러 개 동시 선택 가능)
                 여러 역할 지정 시 그중 하나만 있어도 명령 사용 가능
                 서버 관리자는 역할 제한과 관계없이 모든 명령 사용 가능
                 "역할 추가" — 기존 역할에 누적 / "다시 설정" — 목록 교체
                 역할 비우고 저장 → 해당 명령 전체 허용
                 /명령설정 자체는 제한 불가
                 저장: config.json → command_roles
                   예: { "팀정하기": [123456789, 987654321] }

  관리 대상 명령 (13개):
    ping, 공지설정, 공지, 멤버목록, 채팅삭제, 팀정하기,
    tft알림설정, tft패치, tft소식, 스팀알림설정, 스팀할인,
    출석조회, 활동통계

[activity_tracker.py]
  /출석조회    — Manage Guild 필요
                 멤버(기본: 본인) 출석일수·음성·메시지 요약 + 최근 7일
  /활동통계    — Manage Guild 필요
                 서버 전체 활동 CSV ephemeral 첨부

[team/cog.py]
  /팀정하기    — 권한 제한 없음 (일반 멤버 사용 가능, /명령설정으로 역할 제한 가능)
                 Embed 3구역(팀 구성 / 멤버 선택 / 실행) + 버튼 row 분리
                 팀 구성 버튼(2:2, 3:3, 4:4, 5:5, 2:2:2:2) + Modal 직접입력
                 멤버 UserSelect (서버 전체 검색, 최대 25명, 봇 선택 시 제외)
                 인원 일치 시 랜덤 팀 배정, 다시 섞기·멤버 수정
                 View 세션 30분 후 만료

[tft/cog.py]
  /tft알림설정 — Manage Guild 필요. 자동 알림 채널 지정
  /tft패치     — 최신 공식 패치 노트를 규칙 기반으로 상향/하향 요약
  /tft소식     — 공식 새 소식 최근 5건 (제목+링크)

[steam/cog.py]
  /스팀알림설정 — Manage Guild 필요. 알림 채널 + 최소 할인율 설정
  /스팀할인    — 할인 게임 목록 조회 (페이지 버튼)

■ 8. 팀 정하기 (team)
--------------------------------------------------------------------------------
모듈: src/team/cog.py

UI 구성:
  Row 0: 2:2 | 3:3 | 4:4 | 5:5 | 2:2:2:2        ← 1️⃣ 팀 구성
  Row 1: ✏️ 직접입력                              ← 1️⃣ 팀 구성
  Row 2: 👥 UserSelect (서버 멤버 검색·선택)       ← 2️⃣ 멤버 선택
  Row 4: 🎲 팀 나누기 | 선택 해제 | 🔄 초기화     ← 3️⃣ 실행
  Embed: 1️⃣ 팀 구성 / 2️⃣ 멤버 선택 / 3️⃣ 실행 안내

멤버 목록:
  · Discord UserSelect로 서버 전체 멤버 검색·스크롤
  · 멤버 페이지 이전/다음 버튼 불필요
  · 한 번에 최대 25명 선택
  · UserSelect에서 봇을 선택하면 콜백에서 자동 제외하고 안내

팀 배정:
  · parse_team_format("3:3:2") → [3, 3, 2]
  · 선택 인원 수 == sum(sizes) 일 때만 실행
  · random.shuffle 후 팀별 슬라이스
  · 결과 Embed + TeamResultView (다시 섞기 / 멤버 수정)

제한:
  · UserSelect는 한 번에 최대 25명 선택 (Discord API)
  · 직접입력 팀 구성도 합계 25명 이하로 제한
  · VIEW_TIMEOUT = 1800초 (30분)


■ 9. 활동 집계 (activity_tracker)
--------------------------------------------------------------------------------
저장 파일 : data/activity.json (KST Asia/Seoul 기준 일별)
            ACTIVITY_FILE 환경 변수로 경로 변경 가능

집계 항목:
  voice_joins     — 음성 채널 입장(또는 채널 이동) 횟수
  voice_seconds   — 음성 체류 초 (자정 넘기면 날짜별 분배)
  voice_messages  — 음성/스테이지 채널 채팅 수
  messages        — 일반 텍스트 채널 메시지 수

출석 판정:
  attended  — 해당 날짜에 위 항목 중 하나라도 > 0
  qualified — voice_seconds >= min_voice_seconds (API 쿼리, 기본 0)

봇 재시작 시:
  이미 음성에 있는 멤버는 on_ready에서 세션만 동기화
  (재시작 직전 구간 초는 누락될 수 있음)


■ 10. TFT 패치·소식 (tft)
--------------------------------------------------------------------------------
공식 사이트 HTML(__NEXT_DATA__) 파싱. OpenAI 등 유료 API 미사용.

  client.py    — 패치 노트·새 소식 카드 수집
  summarize.py — 변경 줄 상향/하향/조정 분류
  store.py     — 알림 채널·이미 게시한 글 ID (tft_digest.json)
  cog.py       — /tft알림설정 /tft패치 /tft소식, 기본 30분 주기 폴링

처음 채널 설정 시 최신 패치 1건 게시, 이후 새 글만 알림.


■ 11. Steam 할인 (steam)
--------------------------------------------------------------------------------
Steam Store 검색/태그 HTML 파싱. 한국 스토어(kr) 가격 기준. API 키 불필요.

  client.py — 할인 게임·시즌 세일 이벤트 수집
  store.py  — 알림 채널·최소 할인율·게시 이력 (steam_digest.json)
  cog.py    — /스팀알림설정 /스팀할인, 기본 60분 주기 폴링

시즌 세일 시작 시 별도 공지 1회, 세일 기간 중 개별 할인 알림 일시 중단.


■ 12. REST API
--------------------------------------------------------------------------------
실행: python src/main.py  (discord.py 봇과 uvicorn을 같은 프로세스에서 실행)
문서: http://localhost:8000/docs

  GET /health
  GET /api/v1/guilds/{guild_id}/attendance-report
  GET /api/v1/guilds/{guild_id}/members/summary
  GET /api/v1/guilds/{guild_id}/members/{user_id}

GUILD_ID가 설정되어 있으면 다른 guild_id 요청은 403.

■ 14. 발생했던 오류 / 주의
--------------------------------------------------------------------------------
  DISCORD_TOKEN 미설정
  → .env 없거나 DISCORD_TOKEN 비어 있음

  PrivilegedIntentsRequired
  → Message Content / Server Members Intent 미활성화

  슬래시 명령이 안 보임
  → GUILD_ID 설정 후 재시작(즉시 sync) 권장

  /팀정하기에서 봇 계정을 선택함
  → UserSelect는 봇을 목록에서 숨길 수 없어 선택 후 자동 제외·안내

  Railway 재배포 후 설정·알림 채널 초기화
  → 컨테이너 파일시스템은 휘발성
  → Volume /data + CONFIG_FILE, TFT_DIGEST_FILE, STEAM_DIGEST_FILE 설정
  → Volume 연결 후 채널 재설정 1회 필요

  /채팅삭제 14일 초과 메시지
  → Discord API 제한으로 14일 지난 메시지는 bulk purge 불가

  REST API 401 / 503
  → API_KEY 누락 또는 불일치

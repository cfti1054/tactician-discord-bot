■ 1. 프로젝트 개요
--------------------------------------------------------------------------------
Python + discord.py 기반 Discord 봇.

봇 이름   : Tactician Bot
실행 방법 :
  python src/main.py   봇 + REST API (Railway / 외부 조회)
  python src/bot.py    봇만 실행
주요 기능 :
  · 슬래시 명령 (/ping, /공지설정, /공지, /멤버목록, /출석조회, /활동통계)
  · 공지 채널 설정 + 모달로 공지 임베드 게시
  · 멤버목록 채널 자동 생성·게시 + CSV 다운로드 버튼
  · 음성/메시지 활동 집계 (KST 일별) → activity.json 저장
  · REST API로 기간별 출결·활동 조회 (포인트 계산은 외부 시스템)

■ 4. Discord 설정 (Developer Portal)
--------------------------------------------------------------------------------
[필수 Intent]
  Message Content Intent  — 메시지 수 집계(on_message)에 필요
  Server Members Intent   — 멤버 목록·캐시(guild.chunk / fetch_members)에 필요

  위치: Applications → Bot → Privileged Gateway Intents

[초대 권한 권장]
  OAuth2 → URL Generator
  Scopes : bot, applications.commands
  권한 예시:
    · 메시지 보내기 / 임베드 링크 / 파일 첨부
    · 채널 관리 (멤버목록 채널 자동 생성)
    · 서버 관리 권한은 슬래시 default_permissions와 별개
      (실제 사용 제한은 명령의 Manage Guild 기본 권한으로 걸림)

[Bot Token]
  .env의 DISCORD_TOKEN에 저장. Git에 올리면 안 됩니다.


■ 5. 환경 변수
--------------------------------------------------------------------------------
  DISCORD_TOKEN  — (필수) 봇 토큰
  GUILD_ID       — (선택) 지정 시 해당 서버에 슬래시 명령 즉시 동기화
                   미설정 시 전역 동기화 (반영 최대 약 1시간)
                   설정 시 활동 집계·REST API 접근도 그 서버만 허용
  API_KEY        — (REST API 필수) Authorization: Bearer <API_KEY>
  PORT           — REST API 포트 (기본 8000, Railway는 자동 주입)
  ACTIVITY_FILE  — (선택) 활동 JSON 경로. Railway Volume 예: /data/activity.json

  설정:
    cp .env.example .env
    cp data/config.example.json data/config.json   # 필요 시
    cp data/activity.example.json data/activity.json


■ 6. 슬래시 명령어
--------------------------------------------------------------------------------
[bot.py]
  /ping        — 생존 확인 (Pong!)
  /공지설정    — 공지 올릴 텍스트 채널 지정 → data/config.json 저장
  /공지        — 모달(제목·내용)로 공지 임베드 게시
  /멤버목록    — Manage Guild 필요
                 "멤버목록" 채널 찾거나 생성 후 목록 게시
                 CSV 다운로드 버튼(1시간)

[activity_tracker.py]
  /출석조회    — Manage Guild 필요
                 멤버(기본: 본인) 출석일수·음성·메시지 요약 + 최근 7일
  /활동통계    — Manage Guild 필요
                 서버 전체 활동 CSV ephemeral 첨부


■ 7. 활동 집계 (activity_tracker)
--------------------------------------------------------------------------------
저장 파일 : data/activity.json (KST Asia/Seoul 기준 일별)
            ACTIVITY_FILE 환경 변수로 경로 변경 가능

집계 항목:
  voice_joins     — 음성 채널 입장(또는 채널 이동) 횟수
  voice_seconds   — 음성 체류 초 (자정 넘기면 날짜별 분배)
  voice_messages  — 음성/스테이지 채널 채팅 수
  messages        — 일반 텍스트 채널 메시지 수

출석 판정:
  attended  — 해당 날짜에 위 항목 중 하나라도 > 0
  qualified — voice_seconds >= min_voice_seconds (API 쿼리, 기본 0)

데이터 형태(요약):
  {
    "<guild_id>": {
      "_guild_name": "...",
      "<user_id>": {
        "_user_name": "...",
        "YYYY-MM-DD": {
          "voice_joins": 0,
          "voice_seconds": 0,
          "voice_messages": 0,
          "messages": 0
        }
      }
    }
  }

봇 재시작 시:
  이미 음성에 있는 멤버는 on_ready에서 세션만 동기화
  (재시작 직전 구간 초는 누락될 수 있음)


■ 8. REST API
--------------------------------------------------------------------------------
실행: python src/main.py  (discord.py 봇과 uvicorn을 같은 프로세스에서 실행)
문서: http://localhost:8000/docs

  GET /health
    인증 없음. Railway 헬스체크용.

  GET /api/v1/guilds/{guild_id}/attendance-report
    Query: from, to (YYYY-MM-DD, KST), min_voice_seconds (기본 0)
    기간 내 활동이 있는 멤버 + 일별 상세(attended/qualified)

  GET /api/v1/guilds/{guild_id}/members/summary
    위와 동일, 일별 배열 없음 (대시보드·포인트 배치용)

  GET /api/v1/guilds/{guild_id}/members/{user_id}
    특정 멤버 기간 상세. 데이터 없으면 404.

인증: Authorization: Bearer <API_KEY>
GUILD_ID가 설정되어 있으면 다른 guild_id 요청은 403.

포인트 계산은 API에 포함하지 않음. 외부에서 qualified_days 등을 사용.


■ 9. bot.py / 모듈 구조
--------------------------------------------------------------------------------
main.py
  load_dotenv() → bot.start() + uvicorn.Server.serve() 병렬 실행
  Railway는 PORT를 listen 해야 Public URL이 동작함

bot.py
  load_dotenv() → TOKEN / GUILD_ID
  data/config.json 로드·저장 (공지·멤버목록 채널)
  setup_hook → ActivityTracker Cog 로드
  on_ready
    · 슬래시 sync (guild 또는 global)
    · GUILD_ID 있으면 guild.chunk()로 멤버 캐시
    · 설정된 채널 상태 로그
  슬래시: ping / 공지설정 / 공지 / 멤버목록
  python src/bot.py 로 단독 실행 가능

activity_tracker.py
  ActivityStore  — JSON 읽기/쓰기·기간 집계
  ActivityTracker Cog
    · on_voice_state_update / on_message
    · /출석조회, /활동통계
  setup_activity_tracker(bot, guild_id)

api/
  FastAPI가 bot.get_cog("ActivityTracker").store 를 공유해서 읽기


■ 10. 발생했던 오류 / 주의
--------------------------------------------------------------------------------
  ValueError: DISCORD_TOKEN 미설정
  → .env 없거나 DISCORD_TOKEN 비어 있음
  → cp .env.example .env 후 토큰 입력

  PrivilegedIntentsRequired
  → Message Content / Server Members Intent 미활성화
  → Developer Portal에서 ON 후 재실행

  슬래시 명령이 안 보임
  → GUILD_ID 설정 후 재시작(즉시 sync) 권장
  → 전역 sync는 최대 약 1시간 소요
  → 초대 시 applications.commands 스코프 포함 여부 확인

  REST API 401
  → Authorization: Bearer <API_KEY> 누락 또는 API_KEY 불일치

  REST API 503 API_KEY 미설정
  → Railway Variables / .env 에 API_KEY 추가

  Railway 재배포 후 activity.json 초기화
  → 컨테이너 파일시스템은 휘발성. Volume을 /data 에 달고
    ACTIVITY_FILE=/data/activity.json 설정

--------------------------------------------------------------------------------

  2. .env에 DISCORD_TOKEN, API_KEY (및 선택 GUILD_ID) 설정
